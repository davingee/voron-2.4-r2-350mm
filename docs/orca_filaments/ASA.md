# ASA (Recommended for Voron Parts)

## OrcaSlicer Settings

| Setting | Value | Where in OrcaSlicer |
|---|---|---|
| Nozzle temperature | 240-250C | Filament preset -> `Filament` tab -> Temperature |
| Bed temperature | 100-110C | Filament preset -> `Filament` tab -> Temperature |
| Part cooling fan | 0% first 4 layers, max 30% after | Filament preset -> `Cooling` tab |
| Slow down for cooling | Disabled | Filament preset -> `Cooling` tab |
| Pressure advance | 0.04 (starting point) | Filament preset -> `Filament` tab (search `pressure advance`) |

## Notes
- Keep enclosure closed and preheated (40-50C chamber target).
- If corners lift, raise bed temp toward 110C and slow first layer.

# PLA / PLA+

## OrcaSlicer Settings

| Setting | Value | Where in OrcaSlicer |
|---|---|---|
| Nozzle temperature | 200-220C | Filament preset -> `Filament` tab -> Temperature |
| Bed temperature | 50-60C | Filament preset -> `Filament` tab -> Temperature |
| Part cooling fan | 100% after first 2-3 layers | Filament preset -> `Cooling` tab |
| Slow down for cooling | Enabled | Filament preset -> `Cooling` tab |
| Pressure advance | Tune per spool | Filament preset -> `Filament` tab (search `pressure advance`) |

## Notes
- Keep chamber/exhaust open for PLA; too much enclosure heat can soften filament before the hotend.
- Good for prototypes and non-heat-critical parts, not ideal for enclosed-printer structural parts.

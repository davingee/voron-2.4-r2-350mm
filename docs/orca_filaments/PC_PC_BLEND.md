# Polycarbonate (PC / PC-Blend)

## OrcaSlicer Settings

| Setting | Value | Where in OrcaSlicer |
|---|---|---|
| Nozzle temperature | 260-280C (per spool spec) | Filament preset -> `Filament` tab -> Temperature |
| Bed temperature | 110-115C | Filament preset -> `Filament` tab -> Temperature |
| Part cooling fan | 0% | Filament preset -> `Cooling` tab |
| Pressure advance | Tune per spool | Filament preset -> `Filament` tab (search `pressure advance`) |

## Notes
- PC is moisture-sensitive; dry before printing.
- PC-Blend is usually easier than pure PC.

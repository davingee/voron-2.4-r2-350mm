# Carbon Fiber Reinforced (CF-ABS / CF-ASA / CF-PA)

## OrcaSlicer Settings

| Setting | Value | Where in OrcaSlicer |
|---|---|---|
| Nozzle temperature | Base filament +5C to +10C | Filament preset -> `Filament` tab -> Temperature |
| Bed temperature | Same as base filament | Filament preset -> `Filament` tab -> Temperature |
| Part cooling fan | 0-10% | Filament preset -> `Cooling` tab |
| Retraction | Slightly less than base filament | Filament preset -> `Filament`/`Advanced` tab (search `retraction`) |

## Notes
- Use hardened steel nozzle (0.4 minimum, 0.6 preferred).
- Do not use brass nozzles with CF filaments.

# Nylon (PA / PA12)

## OrcaSlicer Settings

| Setting | Value | Where in OrcaSlicer |
|---|---|---|
| Nozzle temperature | 240-260C | Filament preset -> `Filament` tab -> Temperature |
| Bed temperature | 70-85C | Filament preset -> `Filament` tab -> Temperature |
| Part cooling fan | 0-20% | Filament preset -> `Cooling` tab |
| Pressure advance | Tune per spool | Filament preset -> `Filament` tab (search `pressure advance`) |

## Notes
- Must be dry-printed; nylon absorbs moisture quickly.
- PA12 is usually easier than PA6.

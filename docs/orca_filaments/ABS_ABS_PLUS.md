# ABS / ABS+

## OrcaSlicer Settings

| Setting | Value | Where in OrcaSlicer |
|---|---|---|
| Nozzle temperature | 230-245C | Filament preset -> `Filament` tab -> Temperature |
| Bed temperature | 100-110C | Filament preset -> `Filament` tab -> Temperature |
| Part cooling fan | 0% | Filament preset -> `Cooling` tab |
| Pressure advance | Tune per spool | Filament preset -> `Filament` tab (search `pressure advance`) |

## Notes
- Run enclosed, avoid drafts.
- If layer splitting starts, increase nozzle temp by about 5C.

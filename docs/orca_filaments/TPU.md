# TPU (Flexible)

## OrcaSlicer Settings

| Setting | Value | Where in OrcaSlicer |
|---|---|---|
| Nozzle temperature | 220-235C | Filament preset -> `Filament` tab -> Temperature |
| Bed temperature | 30-45C | Filament preset -> `Filament` tab -> Temperature |
| Part cooling fan | 30-50% | Filament preset -> `Cooling` tab |
| Print speed | 25-40 mm/s max | Process preset -> `Speed` tab |
| Retraction | 0-0.5 mm | Filament preset -> `Filament`/`Advanced` tab (search `retraction`) |
| Pressure advance | Disabled | Filament preset -> `Filament` tab (search `pressure advance`) |

## Notes
- Direct drive works well, but speed must stay low.
- 95A TPU is easiest to run.

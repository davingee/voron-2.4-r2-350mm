# PETG

## OrcaSlicer Settings

| Setting | Value | Where in OrcaSlicer |
|---|---|---|
| Nozzle temperature | 235-250C | Filament preset -> `Filament` tab -> Temperature |
| Bed temperature | 70-85C | Filament preset -> `Filament` tab -> Temperature |
| Part cooling fan | 20-40% | Filament preset -> `Cooling` tab |
| Slow down for cooling | Enabled | Filament preset -> `Cooling` tab |
| Pressure advance | Tune per spool | Filament preset -> `Filament` tab (search `pressure advance`) |

## Notes
- PETG strings more than PLA; keep travel clean and tune retraction/temperature per spool.
- Keep cooling moderate to preserve layer bonding.

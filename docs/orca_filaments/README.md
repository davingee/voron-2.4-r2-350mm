## Where Filament Settings Are In OrcaSlicer
1. Open **Prepare** view.
2. In the right panel, click the **Filament preset name**.
3. Click **Edit Preset** (gear/pencil icon).
4. Use these tabs in the filament editor:
- `Filament` tab: nozzle temp, bed temp, flow ratio, pressure advance.
- `Cooling` tab: fan and cooling behavior.
- `Advanced` tab: advanced filament behavior.
5. Save as a new preset (example: `ASA - Voron350 - DragonHF`).

If a setting is hard to find, use the search box in the preset editor and search the exact setting name.
